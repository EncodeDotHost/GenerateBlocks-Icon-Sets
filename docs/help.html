How to download an icon group and import it into GenerateBlocks Pro.

What this repository is

The repository holds icon sets that are converted into the GenerateBlocks Pro group import format. Each set is split into groups by category and style, for example FontAwesome (Free) (Arrows) or Tabler Icons (Weather) (Outline). Each group is one JSON file. You import only the groups you need, so your Asset Library stays small.

All sets come from open-source projects with permissive licenses. The gallery shows the license and attribution for each set. Each set folder in the repository has a README with the full license text.

  • Bootstrap Icons 1.13.2 - one style, 29 category groups - MIT
  • Font Awesome Free 7.3.1 - Solid, Regular and Brands - CC BY 4.0, attribution required
  • Heroicons 2.2.0 - Outline 24, Solid 24, Solid 20 and Solid 16 - MIT
  • Lucide 1.57.0 - one style, 40 category groups - ISC
  • Material Symbols - Outlined, Rounded and Sharp - Apache 2.0
  • Phosphor Icons 2.1.1 - Thin, Light, Regular, Bold, Fill and Duotone - MIT
  • Remix Icon 4.8.0 - Line and Fill - Apache 2.0
  • Tabler Icons 3.49.0 - Outline and Filled - MIT
  • Zondicons - one group - Public Domain

You need GenerateBlocks Pro

The Asset Library is a GenerateBlocks Pro feature. The free GenerateBlocks plugin cannot import these files. Get GenerateBlocks Pro.

Download a group file

  1. Open the gallery.
  2. Choose a Set, a Style and a Group. The grid shows the icons in that group.
  3. Click Download group-….json above the grid. The file saves to your computer.

To get every group in a style, click All … files on GitHub. That opens the folder in the repository. You can download files one at a time from there, or clone the repository to get all of them.

Import the group into GenerateBlocks Pro

  1. In WordPress, go to Dashboard > GenerateBlocks > Asset Library.
  2. Open the Icons tab.
  3. In the groups panel, click Import and select the group-….json file.
  4. The new group appears in the list. Repeat for each file you want.

The official Asset Library guide has screenshots of each screen.

When you add an icon from the library to a block, GenerateBlocks saves the SVG into the block HTML. After that, the block has no link to the Asset Library.

Notes

  • Group names are fixed. Each file sets its own group name. If you import the same file twice, you get two groups with the same name.
  • Attribution. Font Awesome icons are CC BY 4.0, so your site must show the attribution text. The gallery shows the text for each set that needs it. Bootstrap Icons, Heroicons, Lucide, Material Symbols, Phosphor, Remix Icon, Tabler and Zondicons do not need page attribution.
  • Multisite. Users without the unfiltered_html capability (everyone except super admins on a multisite network) import through the GenerateBlocks Pro SVG allowlist. It removes preserveAspectRatio and lowercases viewBox. The icons still work and keep their colour setting. Single-site administrators are not affected.
  • Problems or requests. Open an issue on GitHub.
